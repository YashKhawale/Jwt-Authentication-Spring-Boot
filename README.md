# 🛡️ Spring Boot JWT Authentication API

This project demonstrates how to implement **JWT (JSON Web Token) Authentication**
using **Spring Boot** and **Spring Security**.  
It provides secure login, token generation, and protected REST APIs.

---

## 📌 Features

- User Registration (Signup)
- User Login (Authentication)
- JWT Token Generation
- Token Validation
- Stateless Authentication
- Protected API Endpoints
- Custom Security Configuration

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot 3.1
- Spring Security
- JWT (JJWT library)
- Maven
- REST APIs

---

## 🧪 Testing with Postman

1. Register user

2. Login to get JWT token

3. Add token in Authorization header

4. Access protected APIs
